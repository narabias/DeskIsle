调研日期：2026-08-22。

## DeskIsle 已实现

| 公开能力 | DeskIsle 原创实现 |
|---|---|
| 桌面分组 | 圆角半透明“收纳岛”，支持移动、缩放、吸附、锁定和独立颜色 |
| 桌面项目 | 文件、文件夹、快捷方式图标网格；双击打开、右键定位、跨岛拖放 |
| Folder Portals | “文件视窗”，实时读取任意文件夹并支持导航、刷新、排序、复制确认 |
| 自动整理 | “归流规则”，支持扩展名、名称与项目类型，按优先级匹配 |
| Quick-hide | 双击空白、托盘或 `Ctrl+Alt+H` 清屏；单个岛可设为清屏例外 |
| Roll-up | 双击标题或菜单收拢为标题胶囊 |
| Peek | “聚焦层”，全局热键前置并提供跨岛搜索 |
| Tabs | 每个岛可拥有多个可重命名、排序、关闭的标签页 |
| Desktop Pages | 多个“场景页”，支持工具条和全局热键切换 |
| Layout snapshots | 原子保存、自动备份、命名快照、恢复、JSON 导入导出 |
| Personalization | 每岛颜色、三档图标、透明度、排序、墨蓝灰 Fluent 风格 |
| Multi-monitor | 使用 Windows 虚拟屏幕坐标并在拖动时保持可见边界 |

## 有意保持不同的地方

- 使用“桌屿 / 收纳岛 / 文件视窗 / 聚焦层”等原创名称和视觉语言。
- 普通岛只保存引用，不移动底层文件；真实复制仅发生在文件视窗，且先确认。
- 不包含 Stardock 的商标、图标、素材、文案或专有代码。
- Windows Explorer 桌面宿主属于未公开接口；无法挂接时自动使用底层窗口兼容模式。
