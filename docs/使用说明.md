# 桌屿 DeskIsle 使用说明

## 启动

双击 `run.bat`，或在项目目录执行：

```powershell
python main.py
```

如果当前电脑尚未安装 PySide6：

```powershell
python -m pip install -r requirements.txt
```

`run-demo.bat` 会以普通窗口打开演示模式，不接管桌面，适合先体验交互。

## 基本操作

- 顶部工具条的 `＋`：新建普通收纳岛、文件视窗、HTML 动画或固定网页。
- 拖动标题栏：移动收纳岛；拖动右下角：缩放。
- 双击标题栏：收拢/展开。
- 标题栏 `•••`：外观与名称、背景媒体、图标大小、排序、锁定、窗口置顶、文件视窗、删除。
- 在图标区按住 `Ctrl` 滚动滚轮：平滑放大/缩小图标。
- 标签栏 `＋`：在同一收纳岛中增加标签页。
- 把资源管理器中的文件拖进普通岛：只添加引用，不移动原文件。
- 把项目从一个普通岛拖到另一个普通岛：只改变虚拟归属。
- 把项目拖进文件视窗：会先明确确认，再执行真实复制。
- 双击桌面空白：快速清屏/恢复。
- 右击桌面空白：打开完整功能菜单。

## 文件视窗

创建时选择一个真实目录，目录内容会实时显示。可进入子目录、返回、向上和刷新。

- 删除文件视窗只删除映射，不删除真实目录。
- 向文件视窗拖入项目属于真实文件复制操作，应用会先弹出确认。
- 目录离线或不可访问时，岛仍保留并显示不可用提示。

## 外观：材质、名称与背景

**全局默认**：桌面空白右键 → `设置…` → `外观`，选择收纳岛材质：

- **简易透明**：最轻量的半透明底色，几乎没有额外性能开销。
- **毛玻璃**：对壁纸做模糊取样，接近 Windows / iOS 的磨砂效果。
- **液体玻璃**：在毛玻璃基础上增加边缘折射高光与通透感。

玻璃取样来源默认是“系统壁纸”（更换壁纸后自动刷新），也可改为“自定义图片”。

**单个收纳岛**：标题栏 `•••` → `外观与名称…`，可以：

- 修改收纳岛名称和色调；
- 选择“跟随全局”或单独的材质；
- 选择背景图片或视频，并调整不透明度与“内缘羽化”（边缘柔和地融入玻璃）。

修改会立即预览，点“完成”保存，点“取消”还原。

背景媒体显示在玻璃之上、图标之下：

- 支持 PNG / JPG / BMP / TIFF 图片，GIF / WebP 动图，以及 MP4 / MOV / WebM / MKV / AVI / WMV 视频；视频静音并自动循环播放。
- 200 MB 以内的文件会复制到 `%LOCALAPPDATA%\DeskIsle\media`，移动或删除原文件不受影响；更大的视频直接引用原路径。
- 收拢后的胶囊同样显示背景图片；没有背景媒体时以玻璃材质为主。
- 标题栏 `•••` → `背景媒体` → `移除背景媒体` 可随时去掉背景。

## 字体

`设置…` → `外观` → `字体（应用于整个桌屿）`：

- 从系统已安装的字体中选择，或点击 `导入字体文件…` 使用 `.ttf / .otf / .ttc` 文件（会复制到 `%LOCALAPPDATA%\DeskIsle\fonts`）。
- 可调整字号；选择“系统默认”即可恢复。

## HTML 动画岛

`＋` → `HTML 动画`，选择一个本地 `.html` 文件，页面中的 CSS / JavaScript / Canvas 动画会持续播放。

- 页面背景设为透明（`background: transparent`）时，动画会直接浮在玻璃材质之上。
- 默认**禁止联网**，只能读取本地文件，更安全；需要加载在线资源时，在该岛菜单中勾选 `允许页面联网`。
- 菜单中可 `更换 HTML 文件…`、`重新加载`、调整 `内容缩放`。
- 收拢后会显示动画的静态画面，展开后继续播放。

## 固定网页岛

`＋` → `固定网页`，输入网址（也可以直接输入关键词进行搜索），网页会像一个固定在桌面上的浏览器窗口：

- 顶部导航栏提供后退、前进、刷新和地址栏，可在菜单中关闭 `显示导航栏`。
- 登录状态会保留，重启后无需重新登录（数据保存在 `%LOCALAPPDATA%\DeskIsle\web`）。
- 菜单中可设置 `自动刷新`（1～60 分钟）、`页面缩放`、`回到固定网址`、`在浏览器中打开`。
- 网页中下载的文件保存到系统“下载”文件夹，完成后托盘会提示。
- 内置网页内核不含 H.264 等专有音视频解码器，个别视频网站可能无法播放，可改用 `在浏览器中打开`。

## 窗口置顶

任意收纳岛的 `•••` → `窗口置顶`：该岛会显示在其他窗口之上（例如把固定网页、待办列表放在最前）。再次点击取消。

## 动态与性能

`设置…` → `动态与性能`：

- `减弱动态效果`：关闭过渡动画，收拢、缩放等操作立即完成。
- `被遮挡时暂停视频与动画`：桌面被全屏或最大化的窗口完全挡住时，自动暂停背景视频和 HTML 动画，减少 CPU/GPU 占用（固定网页不会被冻结，音乐等仍可继续播放）。收纳岛被隐藏或收拢时也会暂停。
- 背景视频帧率：15 / 24 / 30 / 60 帧，数值越低越省电。

## 更新

- 桌屿会在后台定期（约每 20 小时最多一次）检查 GitHub 上 `narabias/DeskIsle` 的最新发布；发现新版本时托盘会提示一次，点击提示即可打开更新窗口。
- 也可以通过托盘菜单 → `检查更新`，或 `设置…` → `更新` → `立即检查更新` 手动检查；在同一页可关闭 `自动检查更新`。
- 点击 `下载并安装` 后，安装包下载完成会先校验 SHA-256，再点 `立即安装`：桌屿会保存布局并退出，安装完成后自动重新打开。
- 不想升级某个版本时点 `跳过此版本`，之后不再提醒该版本。
- 更新只替换程序文件，**不会修改你的布局、设置、背景媒体和网页登录状态**。
- 直接用 Python 源码运行时无法自动安装，更新窗口会提供 `前往下载页面`。

## 归流规则

桌面空白右键 → `归流规则…`：

- 扩展名：支持 `.png;.jpg` 等多个值。
- 名称包含、开头、结尾：忽略大小写。
- 项目类型：文件夹、快捷方式、文档、图片、音视频、压缩包。
- 规则按优先级从上到下匹配，首个命中的目标生效。

自动整理只改变 DeskIsle 内的引用归属，不移动真实文件。

## 场景、聚焦与快照

- 场景页用于区分工作、学习、游戏等布局。
- `Ctrl+Alt+Left / Right` 切换场景页。
- `Ctrl+Alt+Space` 打开聚焦层，所有岛浮到窗口之上，并出现全局搜索框。
- `Esc` 或再次按热键退出聚焦层。
- 布局快照可保存和恢复岛的位置、尺寸、标签、引用及规则。

## 数据安全

- 普通收纳岛永不移动、重命名或删除真实文件。
- 删除普通岛时，其项目会回到 DeskIsle 散放区。
- 退出时会恢复 Windows 原生桌面图标。
- 配置默认保存于 `%LOCALAPPDATA%\DeskIsle`，每次保存都有备份。
- 若进程被强制结束导致原生图标未恢复，可重启 DeskIsle 后正常退出，或在 Windows 桌面右键 → 查看 → 显示桌面图标。

## 参数

```text
python main.py --demo                 普通演示窗口
python main.py --reset                备份后重建默认布局
python main.py --data-dir <目录>      指定数据目录
```
