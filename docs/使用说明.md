# 桌屿 DeskIsle 2.0 使用说明

适用于 2.0.1（2.0 最终版的修订版）。版本变化见 [CHANGELOG.md](../CHANGELOG.md)，安装与开发信息见 [README.md](../README.md)。

> **一句话原则**：普通“收纳岛”只保存文件**引用**——整理、移动、删除收纳岛，都不会移动、重命名或删除原文件。
> 只有把文件拖进“文件视窗”时才会真正移动文件，而且执行前会在桌面上请你确认。

## 快速上手

### 安装

1. 运行 `DeskIsle-Setup-2.0.0-x64.exe`。默认安装到 `%LOCALAPPDATA%\Programs\DeskIsle`，**不需要管理员权限**。
2. 安装向导中可以勾选：
   - **创建桌面快捷方式**；
   - **把命令行工具 deskisle-cli 加入 PATH**（只写入当前用户的 PATH，卸载时移除；给 AI 助手和脚本用）。
3. 在安装向导最后一步勾选 **启动桌屿 DeskIsle** 即可直接打开。想让它开机自动运行，到 **设置 → 桌面 → 启动与性能 → 开机自动启动** 打开。

系统要求：Windows 10 / 11 64 位（推荐 1809 及以上）。网页岛与 HTML 小组件需要 Microsoft Edge WebView2 运行时
（Windows 11 与多数 Windows 10 已自带）。

### 第一次启动

- 桌屿会在每台显示器上铺一层透明的“桌面图层”：它位于桌面图标之上、所有窗口之下，就像壁纸的一部分。
- 默认 **由桌屿显示桌面图标**：Windows 原生桌面图标被隐藏，改由桌屿显示在“桌面散放区”，并按
  [归流规则](#桌面图标与归流规则) 收进各个收纳岛。退出桌屿时原生图标会自动恢复。
- 屏幕顶部居中的黑色胶囊是 **灵动岛**，几乎所有功能都从这里开始。
- 灵动岛下方会出现一张欢迎卡片；点 **知道了** 关闭，点 **打开设置** 直接进入设置。

### 先体验，不碰真实桌面

演示模式以普通窗口运行，使用 `%TEMP%\DeskIsleDemo` 里的示例文件和独立数据，**不挂接、不改动真实桌面**：

- 源码：双击 `run-demo.bat`，或执行 `python main.py --demo`；
- 安装版：在命令提示符中执行 `"%LOCALAPPDATA%\Programs\DeskIsle\DeskIsle.exe" --demo`。

演示模式下图层顶部会显示“演示模式 · 不会改动真实桌面”。

### 从 1.x 升级

直接覆盖安装即可（安装前先在托盘菜单中退出旧版）。第一次启动 2.0 时：

- 旧布局会先原样备份为布局快照 **“升级到2.0之前的布局”**（**设置 → 桌面 → 布局快照**，可随时恢复），然后自动迁移；
- 收纳岛、标签页、文件视窗、预设、归流规则、背景媒体、字体和快照全部保留；
- 1.x 的“HTML 动画岛”和“固定网页岛”合并为 **网页岛**；
- 强调色改为 **只取自壁纸**，1.x 的自定义配色与单个岛的色调不再使用；
- 把文件拖进 **文件视窗** 改为“确认后移动”（1.x 为复制），见 [文件视窗](#文件视窗)。

## 认识桌屿

| 名称 | 是什么 |
| --- | --- |
| **灵动岛** | 主显示器顶端的黑色胶囊：预设、搜索、清屏、新建、撤销、正在播放与设置都在这里 |
| **收纳岛** | 桌面上的玻璃卡片。分为普通收纳岛（收纳图标引用）、文件视窗、网页岛和小组件 |
| **桌面散放区** | 没有收进任何收纳岛的桌面图标，直接排列在桌面上 |
| **预设** | 一台显示器上的一整套收纳岛布局，例如“工作”“游戏”，可随时切换 |
| **面板** | 从灵动岛“长”出来的非模态面板：新建、预设、搜索、正在播放 |
| **通知 / 确认卡片** | 出现在灵动岛下方：提示信息，或请你确认一个操作 |

每台显示器各有一个图层、各有自己的预设；灵动岛只出现在主显示器上（其他显示器的预设在灵动岛的预设面板与桌面右键菜单中切换）。

## 灵动岛与面板

### 灵动岛

从左到右依次是：

| 部分 | 作用 |
| --- | --- |
| 预设名称与圆点 | 当前预设，圆点表示预设数量。**点击**打开预设面板；**滚动滚轮**快速切换预设 |
| 搜索 | 打开搜索面板（`Ctrl+Alt+F`） |
| 清屏 / 恢复显示 | 隐藏或唤回全部收纳岛（`Ctrl+Alt+H`） |
| ＋ | 打开新建面板 |
| 撤销 | 只在可以撤销时出现，撤销上一次排布（`Ctrl+Alt+Z`） |
| 正在播放 | 有媒体在播放时出现：封面与跳动的音量条。**点击**打开正在播放面板，**中键**播放 / 暂停 |
| 退出聚焦层 | 只在聚焦层中出现 |
| 设置 | 打开设置窗口 |

- **右键灵动岛**：打开与桌面右键相同的完整菜单。
- 鼠标经过时灵动岛会轻微放大，可在 **设置 → 外观 → 动效 → 灵动岛悬停放大** 关闭。
- 清屏后灵动岛会稍微变淡，但始终可以点击。

### 面板

新建、预设、搜索、正在播放面板都从灵动岛展开，**不是模态窗口**：点面板外的空白处、按 `Esc`，或再次点击同一个按钮即可收回，
桌面上的其他操作不受影响。面板显示在所有收纳岛（包括置顶岛和网页）之上；按住面板空白处可以拖到别处，关闭后回到原位。

**新建面板**

| 分组 | 项目 | 说明 |
| --- | --- | --- |
| 岛屿 | 收纳岛 | 收纳桌面图标，可分多个标签页 |
| | 文件视窗 | 选择一个真实文件夹，实时显示它的内容 |
| | 网页 | 输入网址或从“常用”中选择，点 **固定到桌面** |
| | 本地 HTML 动画 | 选择一个本地 `.html` 文件（动画、小工具或看板） |
| 小组件 | 时钟、天气、正在播放、待办 | 见 [小组件](#小组件) |
| | 你的自定义小组件 | 自定义文件夹中的每个小组件都会列在这里 |
| | 自定义小组件… | 打开 **设置 → 小组件 → 自定义小组件** |

新的岛会放在打开面板的那台显示器上，自动找一块不与其他岛重叠的空位。

**预设面板**：列出当前显示器的全部预设（名称、岛屿数量）。点击切换；**双击**重命名；**右键**复制或删除。
底部可以 **新建空白预设**、**复制当前预设**、**保存布局快照**。详见 [预设](#预设)。

**搜索面板**：见 [搜索](#搜索)。

**正在播放面板**：大封面、进度条与完整的播放控制，和 [正在播放小组件](#正在播放) 相同。

### 通知与确认卡片

- 通知卡片出现在主显示器右下角，几秒后自动消失；有的带操作按钮（例如“查看”“查看日志”，待办提醒的“完成”“10 分钟后”），
  带操作的提醒会一直保留到你处理。
- 确认卡片出现在灵动岛下方，用于需要你决定的操作（删除收纳岛、删除预设、恢复或删除快照、导入布局、把文件移进文件视窗……）。
  点确认按钮执行，点 **取消** 或按 `Esc` 放弃。
- 通知和确认卡片都显示在所有收纳岛与网页之上，按住卡片空白处可以拖开；设置窗口在前台时，确认卡片显示在设置窗口里。
- 由 AI 助手发起的操作会标注 **“来自 AI 助手”**，见 [AI 助手与命令行](#ai-助手与命令行)。

## 收纳岛

### 移动、缩放与收拢

- **移动**：按住标题栏拖动。同一显示器上的岛 **永远不会重叠**，拖动时旁边的岛会实时让位；
  停在另一个岛上片刻（会提示“停留片刻即可交换位置”），两者交换位置。
- **换显示器**：直接把岛拖到另一台显示器上，它会加入那台显示器的当前预设。
- **缩放**：拖动边缘或右下角。旁边的岛会实时让出空间，并预览让位后的位置。
- **收拢 / 展开**：**双击标题栏**（或右键菜单 → 收拢 / 展开）。收拢后只剩一条胶囊大小的标题，不再占用展开时的空间；
  展开时如果空间不够，会推开邻居。
- **重命名**：**双击标题文字**，回车确认，`Esc` 取消。
- **撤销**：任何排布变化（移动、缩放、交换、自动排布）都可以用 `Ctrl+Alt+Z` 或灵动岛的撤销按钮撤销。
- 右键菜单 → **锁定位置** 后，这个岛不能被拖动或缩放，也不会被其他岛推开。

### 标签页

一个普通收纳岛可以有多个标签页（例如“文档”“图片”“项目”）：

- 点标题栏右侧的 **新建标签**（＋），或右键菜单 → **添加标签页**；
- **单击**标签切换，**双击**重命名，**中键**关闭；
- 关闭标签页时，其中的图标会并入同一岛的其他普通标签页（没有时回到桌面散放区），不会丢失；
- 可以把图标直接拖到某个标签上，放进那个标签页。

### 图标

| 操作 | 方法 |
| --- | --- |
| 打开 | 双击图标 |
| 选择 | 单击；`Ctrl` + 单击多选；`Shift` + 单击连选；在空白处拖出选择框 |
| 调整顺序 | 在岛内拖动，其他图标会平滑让位；拖到边缘会自动滚动 |
| 放进其他收纳岛 | 拖到那个岛上（只移动引用，提示“添加到此岛（不移动原文件）”） |
| 放回桌面 | 拖到桌面空白处，进入桌面散放区 |
| 拖到资源管理器、邮件、聊天窗口 | 直接拖出去即可（标准文件拖放，见下方说明） |
| 放大 / 缩小 | 在图标区按住 `Ctrl` 滚动滚轮，或右键菜单 → 图标大小（小 / 中 / 大） |
| 右键 | 打开、在资源管理器中显示、复制路径、**更多（Windows 菜单）…**（系统原生右键菜单）、从收纳岛移出（不删除文件）、移除失效引用 |

- 从资源管理器把文件拖进普通收纳岛：**只添加引用**，原文件留在原处。
- 原文件被删除或移走后，图标会变成“失效”状态；右键 → **移除失效引用** 可一次清理。
- 把图标拖到资源管理器等程序时，文件操作由目标程序完成，和从 Windows 桌面拖动一样：
  拖到同一磁盘的文件夹默认 **移动**，拖到其他磁盘默认 **复制**；拖动时按住 `Ctrl` 复制、`Shift` 移动、`Alt` 创建快捷方式。

### 排序

右键菜单 → **排序**：**手动**、**名称**、**类型**、**修改时间**，可勾选 **降序**；**按名称重新排列一次** 会把当前顺序整理一遍
并保持为手动顺序。在已排序的标签页里拖动图标，会自动切换为手动排序（与资源管理器一致）。

### 收纳岛右键菜单

在标题栏点 **•••（更多）** 或右键标题栏 / 空白处打开。不同类型的岛菜单略有不同：

| 菜单项 | 说明 |
| --- | --- |
| 重命名、添加标签页 | 普通收纳岛 |
| 文件视窗 | 显示 / 更换文件夹…、回到根目录、改回普通收纳岛 |
| 图标大小、排序 | 文件类收纳岛 |
| 网页相关 | 见 [网页岛](#网页岛与本地-html) |
| 小组件相关 | 见 [小组件](#小组件) |
| **材质** | 跟随全局 / 液态玻璃 / 毛玻璃 / 清透 |
| **背景媒体** | 选择图片 / GIF / 视频…、清除背景媒体 |
| **胶囊模式（悬停展开）** | 平时收成一枚小胶囊，鼠标停留片刻临时展开 |
| **锁定位置** | 不能被拖动、缩放或推开 |
| **窗口置顶** | 显示在所有窗口之上（适合待办、时钟、网页） |
| **清屏时保持显示** | 清屏后这个岛仍然留在桌面上 |
| 收拢 / 展开 | 同双击标题栏 |
| **删除** | 先确认；普通收纳岛中的图标回到桌面散放区，文件不受影响 |

### 胶囊模式

开启 **胶囊模式（悬停展开）** 后，岛平时只是一枚带名称的小胶囊；鼠标停在上面一会儿（默认 260 毫秒，
**设置 → 桌面 → 唤醒与快捷键 → 胶囊悬停预览** 可调）就会临时展开预览，移开后自动收回。**双击胶囊** 退出胶囊模式。
胶囊可以像普通岛一样拖动。

### 背景媒体

右键菜单 → **背景媒体 → 选择图片 / GIF / 视频…**，为单个岛设置背景：

- 支持 PNG、JPG、BMP、WebP、GIF 动图，以及 MP4、WebM、MOV、MKV 视频；视频 **静音循环** 播放。
- 200 MB 以内的文件会复制到数据目录的 `media` 文件夹，之后移动或删除原文件也不受影响；更大的视频直接引用原路径。
- 背景显示在玻璃之上、图标之下；岛被隐藏、收拢或被全屏窗口挡住时会暂停。
- **清除背景媒体** 随时去掉。

### 窗口置顶

**窗口置顶** 让这个岛浮在所有窗口之上，例如把待办、时钟或一个网页放在最前面。再次点击取消。
置顶的岛依然遵守“不重叠”规则。

## 文件视窗

文件视窗把一个真实文件夹“开”在桌面上：文件夹里新增、删除或改名的文件会实时显示。

- **创建**：新建面板 → **文件视窗**，选择文件夹；或在普通收纳岛的右键菜单 → **文件视窗 → 显示文件夹…**。
- **浏览**：双击子文件夹进入；标题栏的 **上一级** 返回；路径栏可以点击任意一级；**在资源管理器中打开** 打开当前文件夹；
  右键菜单 → **回到根目录**。
- **把文件拖进文件视窗 = 真正移动文件**：桌屿会先弹出确认卡片“把……移动到……？”，点 **移动** 后才执行。
  移动通过 Windows 外壳完成，可以在资源管理器中按 `Ctrl+Z` 撤销。
- 从文件视窗拖到普通收纳岛只添加引用；拖到资源管理器时由资源管理器处理（见上文）。
- **删除文件视窗只删除这个视图**，真实文件夹和其中的文件不受影响；**改回普通收纳岛** 同理。
- 文件夹不可用（被移动、删除，或移动硬盘没有连接）时，岛会保留并显示“找不到这个文件夹”；文件夹回来后一分钟内自动恢复。

## 网页岛与本地 HTML

网页岛使用 Windows 自带的 **Microsoft Edge WebView2**（与 Edge 浏览器同一内核）。

### 固定一个网站

新建面板 → **网页**，输入网址（也可以直接输入关键词搜索）或点“常用”中的网站，然后点 **固定到桌面**。

- 网页可以像浏览器一样直接操作；**登录状态会被记住**（保存在数据目录的 `web\WebView2`）。
- 顶部导航栏：后退、前进、刷新 / 停止、回到主页、当前网址、缩小 / 放大。**点击网址**（或右键菜单 → 更改网址…）会在标题栏出现地址框，
  输入新网址后回车打开；标题栏的 **在浏览器中打开** 用默认浏览器打开当前页面。
- 网页中按 `Ctrl` + 滚轮缩放，缩放比例会被记住。
- 网页里“在新窗口打开”的链接交给默认浏览器；下载的文件保存到系统“下载”文件夹，完成后桌面会提示。
- 右键菜单：**更改网址…**、**回到固定网址**、**重新加载**、**在浏览器中打开**、**导航栏**（显示 / 隐藏）、
  **自动刷新**（关闭 / 1 / 5 / 15 / 30 / 60 分钟）、**页面缩放**（50%–200%）。

### 本地 HTML 动画

新建面板 → **本地 HTML 动画**，选择一个 `.html` 文件。CSS / JavaScript / Canvas 动画会持续播放：

- 页面背景设为 `background: transparent` 时，动画直接浮在玻璃上。
- **默认禁止联网**，只能读取本地文件；需要在线资源时，右键菜单勾选 **允许本地页面联网**。
  拦截的是普通网页请求（页面、图片、脚本、接口），WebSocket 无法拦截，请只打开来源可信的文件。
- 本地 HTML 运行在独立的隐私会话中，不会读写网页岛的登录信息，也不会留下浏览数据。
- 在本地页面上右键打开的是桌屿的岛菜单。

### 显示方式

**设置 → 桌面 → 启动与性能 → 网页显示方式**：

- **自动**（默认）：使用窗口模式——网页可以直接点击、滚动、输入中文；只有在网页能放到玻璃下层时才使用合成模式。
- **合成（实验）**：网页嵌在玻璃岛里，菜单、阴影和拖过来的岛都能盖在网页上方；部分电脑上点击与输入不稳定，网页没反应时请改回 **自动**。
- **窗口**：网页始终放在独立的子窗口中，兼容性最好；其他岛拖过时会被网页盖住（面板、确认卡片与通知不受影响），
  拖动或缩放网页岛时网页暂时隐藏，松手后恢复。

网页里右键也会弹出岛屿菜单（可删除）。HTML 小组件在窗口模式下顶部留有一条拖动条：按住拖动，右键打开菜单。

被全屏或最大化窗口挡住、清屏或收拢时，网页会暂停渲染以节省资源（声音等可以继续）。

### 没有 WebView2 运行时

岛内会提示“未检测到 Microsoft Edge WebView2 运行时”。点 **获取 WebView2**（或访问
https://developer.microsoft.com/microsoft-edge/webview2/ ）安装“常青版引导程序”，然后点 **重试**，无需重启桌屿。
其他功能不受影响，也可以点 **用浏览器打开**。

## 小组件

小组件也是收纳岛：可以移动、缩放、换材质、置顶、设为胶囊。新建面板 → 小组件 中添加。
在小组件 **任意位置右键** 都会打开它的菜单（含 **删除**）；按住空白处即可拖动。
**设置 → 小组件** 里是所有同类小组件的默认设置，单个小组件可以在它的右键菜单中另行设置。

### 时钟

- 三种样式：**数字**、**指针**、**翻页**；**24 小时制**（关闭后显示上午 / 下午）、**显示秒**（翻页样式没有秒）、**显示农历**（农历、节气与传统节日）。
- 把时钟岛拉高，下方会出现 **月历**（带农历日期），可以 **上个月 / 下个月 / 回到本月**。
  有待办的日期显示小圆点（有过期未完成的为红点），**点击** 这一天可以查看当天的待办。
- 右键菜单：24 小时制、显示秒（翻页样式没有）、显示农历与节气、样式。

### 天气

- 显示当前温度、天气、体感、最高 / 最低温、湿度、空气质量、紫外线和未来 5 天预报。
- **位置**：默认 **自动定位**——使用 Windows 定位服务（需要在 Windows“设置 → 隐私和安全性 → 定位”中允许桌面应用访问位置），
  不可用时按网络位置估算。也可以关闭自动定位，在 **城市** 中搜索并选择（例如“杭州”“Tokyo”）。
- 数据来自 **MSN 天气**（与 Windows 任务栏天气相同），不可用时改用 **Open-Meteo**；可切换 **使用华氏度**。
- 约每 20 分钟自动刷新；点小组件右上角的刷新按钮或右键菜单 → **立即刷新** 手动刷新；**位置与单位…** 打开设置。
- 获取失败时会显示原因，并提供 **重试** 和 **设置位置**。
- 隐私：**只有桌面上有天气小组件时** 才会定位和联网；发送的经纬度只保留两位小数（约 1 公里）。

### 正在播放

- 自动显示 Windows 中正在播放的媒体（QQ 音乐、网易云音乐、Spotify、浏览器里的视频等，凡是出现在系统媒体浮窗里的都可以）：
  封面、标题、艺术家、进度。切歌、暂停会立即更新；同时有多个来源时优先显示正在播放的那个。
- 小组件的玻璃底色、进度条和播放按钮跟随封面的主色渐变；把小组件拉高时改为上封面、下文字。
- **网易云音乐** 默认不向系统报告播放信息：请在网易云音乐的 **设置** 中打开 **SMTC**（系统媒体传输控制）相关选项；
  桌屿检测到网易云在运行却读不到信息时，会在小组件里提示。歌词与精确进度需要 BetterNCM 等插件，桌屿暂不支持。
- 播放 / 暂停、**上一首**、**下一首**、拖动进度、**随机播放**、**循环**（不循环 / 列表循环 / 单曲循环），具体取决于播放器是否支持。
- 同时有多个播放器时，点 **切换播放器（N 个）** 切换。
- 灵动岛上同步显示迷你控件（中键播放 / 暂停）。右键菜单 → **打开播放器**。

### 待办

- 在底部输入框输入后回车添加；点圆圈勾选完成（打勾后平滑收起）；**双击文字** 编辑；拖动左侧把手排序；点 × 删除。
- 已完成的项目收在顶部 **已完成 N** 里，点一下展开 / 收起，展开后可以 **清除**；右键菜单也有 **清除已完成**。
- **日期**：点项目上的日期标签（没有日期时，鼠标移到项目上会出现日历按钮）打开日期卡，在月历里选一天，再选 **全天** 或 09:00 / 12:00 / 18:00 / 21:00，
  点 **确定**；**清除日期** 去掉日期。设置了日期的待办同时出现在 [时钟](#时钟) 的月历上。
- **截止时间**：在内容后面加一个空格和 `@`，例如：

  | 写法 | 含义 |
  | --- | --- |
  | `交周报 @明天 18:00` | 明天 18:00 |
  | `开会 @周五` / `@下周一 上午9点` | 本周五 / 下周一 9:00 |
  | `@3月8日`、`@2026-12-01` | 指定日期 |
  | `@明晚八点`、`@后天 下午3点半` | 口语说法 |

- **提醒**：到点时弹出置顶提醒卡片，同时发送 Windows 系统通知；卡片上可以 **完成** 或 **10 分钟后** 再提醒。
  只设了日期（全天）的项目在当天 09:00 提醒；桌屿没运行时错过的提醒，下次启动时汇总提醒一次；设成已经过去的时间不会提醒。
- 过期未完成的项目显示为红色。
- 待办保存在布局数据中，随布局快照一起备份。

## 自定义小组件

你可以用 **HTML** 或 **Qt Quick（QML）** 编写自己的小组件，也可以让 AI 助手替你写。所有内容放在 **自定义文件夹** 中，
保存文件后立即生效（热重载），无需重启。

### 自定义文件夹

默认位于 `%LOCALAPPDATA%\DeskIsle\custom`，可在 **设置 → 小组件 → 自定义小组件 → 自定义文件夹** 中 **打开**、**更换…** 或 **恢复默认**。
第一次使用时桌屿会创建说明文件 `README.md`、示例 `theme.json` 和两个示例小组件——`hello`（“你好，桌屿”，网页示例）与
`qml-sample`（“QML 示例”，跟随主题色的进度环），之后不会覆盖你的修改：

```
custom/
  README.md              说明（只在首次创建）
  theme.json             视觉参数
  widgets/
    hello/               一个小组件 = 一个文件夹
      widget.json
      index.html
    qml-sample/
      widget.json
      Widget.qml
```

### 创建一个小组件

- **设置 → 小组件 → 自定义小组件 → 新建小组件**：输入名称，点 **创建**，桌屿会从 HTML 模板生成一个文件夹，用任意编辑器修改即可；
- 或者自己在 `widgets` 下新建文件夹（文件夹名只能包含字母、数字、点、下划线和连字符）；
- 放到桌面：点灵动岛的 ＋，在“小组件”分组里选择它；或在设置的小组件列表中点 **添加到桌面**。

`widget.json`：

```json
{
  "name": "每日一句",
  "type": "html",
  "entry": "index.html",
  "size": [320, 200],
  "description": "显示一句话",
  "network": false,
  "version": "1.0"
}
```

| 字段 | 说明 |
| --- | --- |
| `name` | 显示名称（最多 40 字） |
| `type` | `html` 或 `qml`；省略时按入口文件扩展名判断 |
| `entry` | 入口文件，默认 `index.html` / `Widget.qml`，必须在小组件文件夹内 |
| `size` | 新建时的默认宽高（像素，140–1600） |
| `description` | 新建面板中显示的说明 |
| `network` | HTML 小组件是否允许联网，默认 `false` |
| `version` | 版本号（可选） |

没有 `widget.json` 时，只要文件夹里有 `index.html` 或 `Widget.qml` 也能识别。

### HTML 小组件

运行在 WebView2 中，页面背景透明，默认不能联网。页面里可以使用 `window.deskisle`：

| 接口 | 作用 |
| --- | --- |
| `deskisle.theme` | 当前主题：`dark`，颜色 `accent`、`accentSoft`、`onAccent`、`text`、`textDim`、`textFaint`、`hairline`、`danger`，以及 `fontFamily`、`fontSize`、`radius` |
| `deskisle.config` | 这个小组件岛自己的设置（对象） |
| `deskisle.setConfig(key, value)` | 保存一项设置（随布局保存，重启后仍在） |
| `deskisle.on("theme" \| "config", callback)` | 主题或设置变化时回调 |
| `deskisle.openUrl(url)` | 用默认浏览器打开链接 |
| `deskisle.notify(title, text)` | 在灵动岛下方显示一条通知 |
| `deskisle.menu()` | 打开这个岛的右键菜单 |
| `deskisle.uid`、`deskisle.version` | 岛的编号、桌屿版本 |

页面还会得到同名的 CSS 变量（`--deskisle-accent`、`--deskisle-text`、`--deskisle-fontFamily` 等），以及
`<html data-deskisle-theme="dark|light">`，主题变化时自动更新。最小示例：

```html
<!doctype html>
<html><head><meta charset="utf-8">
<style>
  html, body { margin: 0; height: 100%; background: transparent;
               color: var(--deskisle-text); font-family: var(--deskisle-fontFamily), sans-serif; }
  .box { height: 100%; display: grid; place-items: center; font-size: 20px; }
</style></head>
<body><div class="box" id="t">你好</div>
<script>
  const n = (window.deskisle && deskisle.config.n) || 0;
  document.getElementById("t").textContent = "第 " + (n + 1) + " 次打开";
  if (window.deskisle) deskisle.setConfig("n", n + 1);
</script></body></html>
```

### QML 小组件

`Widget.qml` 的根元素会填满岛的内容区，可以直接使用这些对象：

| 对象 | 内容 |
| --- | --- |
| `Theme` | `text`、`textDim`、`accent`、`hairline`、`fontFamily`、`dark`、`reduceMotion` 等 |
| `Clock`、`Weather`、`Player`、`Todo` | 时钟（含农历）、天气、正在播放、待办的数据与操作 |
| `Desk` | 桌屿主控对象 |
| `widget` | 当前小组件岛：`widget.uid`、`widget.widgetConfig`；保存设置用 `Desk.act(widget.uid, "widgetConfig", {...})` |

安装版只保证 `QtQuick`、`QtQuick.Shapes`、`QtQuick.Layouts`、`QtQuick.Effects` 模块可用（其他 Qt 模块在打包时被精简）。
可以参考示例文件夹 `widgets/qml-sample`。

### theme.json：视觉参数

```json
{ "radius": 22, "smallRadius": 12, "glassStrength": 1.0, "shadow": 1.0, "motion": 1.0, "fontScale": 1.0, "headerHeight": 44 }
```

| 参数 | 作用 |
| --- | --- |
| `radius` / `smallRadius` | 收纳岛圆角 / 按钮与菜单圆角（像素） |
| `glassStrength` | 玻璃折射强度倍数 |
| `shadow` | 阴影倍数 |
| `motion` | 动画时长倍数（2 = 慢一倍，0 = 关闭动画） |
| `fontScale` | 字号倍数 |
| `headerHeight` | 标题栏高度 |

文件里不能写注释；强调色只来自壁纸，不能在这里修改。

### 设计建议与排错

- 背景保持透明，文字用 `Theme.text` / `Theme.textDim`（或对应 CSS 变量），只用一个强调色；正文 12–14 px，四周留出 14 px 以上的边距；
  动画遵守 `Theme.reduceMotion`。
- `widget.json` 写错、找不到入口文件等问题会显示在 **设置 → 小组件** 的列表中，同时显示在岛内，并提供 **打开文件夹** 和 **重新加载**。
- QML 语法错误的详细信息写在运行日志里（**设置 → 关于 → 运行日志**）。
- 写给 AI 的完整说明（含小组件 SDK 与命令参考）：**设置 → AI 与扩展 → 说明文档**（`GUIDE.md`）。

## 排布、预设与多显示器

### 排布规则

- 同一台显示器上的收纳岛 **任何时候都不会重叠**，并至少保持 **收纳岛间距**（默认 12 像素，**设置 → 桌面 → 排布**）。
  屏幕顶部为灵动岛留出了一条空间。
- **自动排布**（桌面右键菜单）：一键整理当前显示器上的收纳岛。
- **吸附到网格**（默认开启，网格 8 像素）：移动和缩放时对齐网格。
- 所有排布变化都能用 `Ctrl+Alt+Z` 撤销。

### 预设

- 每台显示器有自己的一组预设，互不影响。
- **切换**：点灵动岛的预设名称打开预设面板；或在预设名称上滚动滚轮；或用 `Ctrl+Alt+←` / `Ctrl+Alt+→`；
  桌面右键 → **预设** 中也可以直接选择。
- **新建空白预设**、**复制当前预设**：在预设面板或桌面右键 → 预设 中。
- **重命名**：在预设面板中双击预设；**复制 / 删除**：右键预设。删除预设会先确认，其中的岛一起删除，图标回到桌面散放区，文件不受影响。
- 断开某台显示器后，它的预设会出现在主显示器的预设列表中（标注“来自 某显示器”），可以临时在主显示器上使用；
  重新连接后照常回到原来的显示器。

### 显示器组合记忆

**设置 → 桌面 → 排布 → 按显示器组合记忆布局**（默认开启）：每一种显示器组合——笔记本单屏、接上扩展屏、连接投影仪——
各自记住一套布局（每台显示器正在使用的预设与每个岛的位置大小），插拔后自动恢复。最多记住 12 种组合。

**重新连接等待**（默认 6 秒）：显示器短暂断开（休眠唤醒、切换输入源）时，先等一会儿再重新排布，避免岛被挤来挤去。

### 布局快照

快照保存完整的布局数据：**所有显示器** 上的收纳岛、标签页、预设、归流规则、待办与小组件设置，以及当时的偏好设置：

- **保存**：**设置 → 桌面 → 布局快照 → 保存快照**、预设面板 → **保存布局快照**，或桌面右键 → 布局快照 → 保存当前布局快照；
- **恢复**：在设置的快照列表中点 **恢复**，或桌面右键 → 布局快照 → 恢复快照。恢复前会先确认，并自动备份当前布局；
- **删除**：在设置的快照列表中点 **删除**，确认后删除这个快照文件（不影响当前布局和其他快照）；
- **导出… / 导入…**：把布局保存为文件，可以在另一台电脑上导入（导入前确认并自动备份；原文件不会被移动或删除）。

桌屿也会自动创建快照：升级到 2.0 之前、恢复快照之前、导入布局之前、安装更新之前、`--reset` 之前。

## 桌面图标与归流规则

### 由桌屿显示桌面图标

**设置 → 桌面 → 桌面图标 → 由桌屿显示桌面图标**（默认开启）：隐藏 Windows 原生桌面图标，由桌屿统一显示与排列。
没有收进收纳岛的图标显示在桌面散放区，操作方式和收纳岛里的图标相同（双击打开、拖动排序、框选、右键菜单）。
退出桌屿时原生图标自动恢复。

关闭后桌屿不再隐藏原生图标，收纳岛照常可用。

### 新项目与自动归流

- 桌屿会自动发现桌面上新出现的文件；也可以在桌面右键 → **扫描桌面新项目**。
- **自动归流**（默认开启）：新出现的项目按归流规则放进对应的收纳岛；关闭后，规则只在点 **立即归流** 时使用。
- 桌面右键 → **立即按规则归流**：对桌面散放区里的项目执行一次全部规则。

### 编辑归流规则

**设置 → 桌面 → 归流规则**：

- **新建规则**：填写规则名称，选择匹配条件，选择要放入的收纳岛，勾选 **启用此规则**，点 **保存规则**。
- 匹配条件：
  - **扩展名**：可写多个，用逗号分隔，例如 `png, jpg, .webp`；
  - **名称包含 / 名称开头 / 名称结尾**：不区分大小写，例如名称开头 `截图`；
  - **项目类型**：文件夹、快捷方式、图片、文档、音频或视频、压缩包（可多选）。
- 规则 **从上到下** 依次匹配，第一条符合的规则生效；用上下箭头调整优先级，也可以编辑或删除。
- 目标收纳岛被删除后，规则会显示“目标收纳岛已不存在”，请重新选择。
- 规则只改变项目在桌屿中的归属，**不会移动、重命名或删除原文件**。

## 清屏、聚焦层与守护

### 清屏

想要一个干净的桌面时：

- **双击桌面空白处**（默认开启，**设置 → 桌面 → 唤醒与快捷键**），再双击一次恢复；
- 或按 `Ctrl+Alt+H`、点灵动岛的清屏按钮、桌面右键 → 清屏、设置窗口侧边栏底部的 **暂时隐藏收纳岛**。

清屏后收纳岛和散放图标淡出，图层顶部提示“已清屏 · 双击桌面空白处恢复”。设置了 **清屏时保持显示** 的岛（例如时钟）会留在桌面上。

### 聚焦层

`Ctrl+Alt+Space`（或桌面右键 → 聚焦层）：所有收纳岛临时浮到窗口之上，不用最小化窗口就能拿到桌面上的文件。
按 `Esc` 或再按一次 `Ctrl+Alt+Space` 退出；灵动岛上也会出现退出按钮。

### 守护桌面层

**设置 → 桌面 → 唤醒与快捷键 → 守护桌面层**（默认开启）：

- 收纳岛被其他程序隐藏或盖住（例如资源管理器重启）时自动恢复；
- 桌屿意外退出时，独立的守护进程会恢复 Windows 原生桌面图标并重新启动桌屿（10 分钟内最多 3 次），
  启动后提示“已自动恢复”。在任务管理器中“结束任务”属于主动退出，不会被重启。

### 全局快捷键

**设置 → 桌面 → 唤醒与快捷键 → 全局快捷键** 可整体关闭。快捷键被其他程序占用时，启动后会提示哪些不可用。
完整列表见 [快捷键与鼠标操作](#快捷键与鼠标操作)。

## 搜索

`Ctrl+Alt+F`、灵动岛的搜索按钮或桌面右键 → 搜索。在搜索框中输入即可，结果分为三组：

- **岛屿**：名称匹配的收纳岛；
- **桌面图标**：所有收纳岛（包括其他预设）和桌面散放区里的项目；
- **电脑里的文件**：
  - 已安装并运行 [Everything](https://www.voidtools.com) 且开启了 **设置 → 桌面 → 使用 Everything 搜索**（默认开启）时，
    直接查询 Everything 的索引，秒出全盘结果；
  - 否则使用桌屿的 **内置索引**：开始菜单、桌面、文档、下载、图片、音乐等用户文件夹，以及文件视窗中的文件夹。

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 选择结果 |
| `Enter` | 岛屿结果：定位到那个岛（必要时切换预设）；图标与文件：打开 |
| `Ctrl+Enter` | 在资源管理器中显示 |
| `Esc` | 关闭搜索 |

结果右侧的按钮可以 **在岛上定位**、**在资源管理器中显示**、**复制路径**。

## 外观

### 主题

**设置 → 外观 → 主题 → 主题模式**：

- **按时间**（默认）：白天 07:00 起浅色、夜间 19:00 起深色，时间可改；
- **跟随壁纸**：按壁纸的明暗自动选择浅色或深色；
- **跟随系统**、**浅色**、**深色**。

**强调色** 自动取自当前壁纸的主色调，用于开关、按钮与选中状态；更换壁纸后随之变化，不能手动指定。

### 材质与玻璃浓度

**设置 → 外观 → 收纳岛 → 默认材质**：

- **液态玻璃**：边缘折射与高光，背后的画面适度模糊；
- **毛玻璃**（默认）：更柔和的磨砂效果，文字最清晰；
- **清透**：背后画面几乎不模糊，像一块透明玻璃。

**玻璃浓度** 控制折射、着色与亮度变化的强度：越低越通透，越高越厚重。单个岛可以在右键菜单 → **材质** 中另选。

### 玻璃背景

**设置 → 外观 → 玻璃背景 → 背景来源** 决定玻璃“折射”的画面，每个岛折射的正是它背后的那一块：

| 来源 | 说明 |
| --- | --- |
| **动态壁纸**（默认） | 实时读取桌面壁纸层的画面，Wallpaper Engine、Lively、视频壁纸也能读到。**动态壁纸刷新率** 默认 12 帧/秒（1–30），画面不动时自动放慢。读取失败时自动改用系统壁纸，并在 **动态壁纸状态** 中说明原因 |
| **系统壁纸** | 当前 Windows 壁纸，按系统的契合度摆放；更换壁纸后自动刷新 |
| **自定义图片** | 选择任意图片作为玻璃背景 |
| **纯色** | 不取样壁纸，最省电 |

### 文字

- **字体**：从系统字体中选择，或 **导入字体文件…**（`.ttf / .otf / .ttc`，会复制到数据目录的 `fonts`）；**恢复默认** 还原。
- **字号**：收纳岛、菜单与设置中正文的大小。
- **文字颜色**：**自动**（跟随主题：深色主题用浅色文字，浅色主题用深色文字）、**浅色**、**深色**、**自定义**（点色块或输入
  `#RRGGBB`）。作用于收纳岛、小组件、灵动岛、菜单、通知和设置窗口，次要文字按比例变淡，强调色不变。

### 动效

- **减弱动态效果**：展开、收拢、让位与主题切换直接完成，不播放过渡动画。
- **灵动岛悬停放大**。

想要更细的调整（圆角、阴影、动画倍速、标题栏高度），使用自定义文件夹中的 [theme.json](#themejson视觉参数)。

## AI 助手与命令行

桌屿可以被 AI 助手（Claude Desktop、Cursor、VS Code、Cherry Studio 等支持 MCP 的客户端）或脚本控制：查看桌面布局、
新建与整理收纳岛、搜索文件、管理待办、编写自定义小组件、截图查看效果……

### 连接 AI 助手（MCP）

1. 打开 **设置 → AI 与扩展**，确认 **允许 AI 助手控制桌屿** 已打开（默认开启），**连接状态** 正常。
2. 在 **MCP 配置** 中点复制，把这段 JSON 加入客户端的 MCP 配置，重启客户端。安装版大致如下：

   ```json
   {
     "mcpServers": {
       "deskisle": {
         "command": "C:\\Users\\<你>\\AppData\\Local\\Programs\\DeskIsle\\deskisle-cli.exe",
         "args": ["mcp"]
       }
     }
   }
   ```

3. 对 AI 说“把桌面上的截图都收进一个叫‘截图’的岛”“在右上角放一个翻页时钟”即可。

### 命令行

```powershell
deskisle-cli list                       # 全部命令（! 表示需要你确认）
deskisle-cli help island.create         # 某条命令的参数
deskisle-cli desk.state                 # 当前布局（JSON）
deskisle-cli island.create --kind widget --widget clock --json '{"config": {"style": "split"}}'
deskisle-cli todo.add --uid <待办岛 uid> --text "交周报 @明天 18:00"
```

- 输出均为 JSON；退出码：0 成功，1 命令出错，2 用法错误，3 桌屿未运行。
- 全局选项：`--demo`（连接演示实例）、`--data-dir`、`--timeout`、`--raw`。
- 没有加入 PATH 时，使用安装目录中的完整路径；源码运行时用 `python main.py --cli <命令> …`。

### 安全

- 只通过本机命名管道通信，**不开放任何网络端口**；随时可以关闭 **允许 AI 助手控制桌屿**。
- **破坏性操作需要你确认**：删除收纳岛、标签页或预设，删除待办或自制小组件，恢复快照、导入布局以及退出桌屿，
  都会先在桌面上弹出标有“来自 AI 助手”的确认卡片，你同意后才会执行。
- 写给 AI 读的完整说明：**设置 → AI 与扩展 → 说明文档**（`GUIDE.md`，可以直接交给 AI 阅读）。

## 性能与省电

- **无人观看时暂停**（默认开启）：全屏或最大化窗口挡住桌面、锁屏或清屏时，暂停视频、网页、动画与动态壁纸读取。
- **视频帧率上限**：收纳岛中视频与 HTML 动画的最高帧率（默认 24 帧）。
- **动态壁纸刷新率**：越低越省电；只想要静态效果时把背景来源改为 **系统壁纸** 或 **纯色**。
- 材质耗电从低到高大致为：纯色背景 < 清透 / 毛玻璃 < 液态玻璃 + 动态壁纸。
- 岛被隐藏、收拢时，背景视频和网页会暂停；隐藏的网页还会请 WebView2 降低内存占用。
- **空闲时释放内存**（默认开启）：启动稳定后、关闭设置窗口后、隐藏收纳岛后，把暂时用不到的内存还给系统
  （拖动中或设置窗口打开时自动顺延），再次使用时按需载回。
- **当前内存占用**：分开显示桌屿本体和网页组件（`msedgewebview2.exe` 进程）占用的内存，可点 **立即释放**。
  任务管理器的“桌屿”分组包含这些网页进程，每个网页岛 / HTML 小组件约 100–200 MB；不需要时删除或收拢网页岛最省内存。

## 更新

- 桌屿会在后台检查 GitHub 上的正式版本（启动后稍等片刻，之后约每 20 小时最多一次），发现新版本时在桌面提示一次，
  点 **查看** 打开 **设置 → 关于**。也可以随时点 **检查更新**，或在托盘菜单中选择 **检查更新**。
- 点 **下载并安装**：下载完成后会校验 SHA-256，并自动保存一份布局快照（“更新前自动备份”），然后桌屿退出、
  安装程序静默运行，完成后自动重新打开桌屿。没有校验值或校验失败都不会安装。
- 不想自动检查时关闭 **自动检查更新**；发现新版本时只提醒，不会自动安装。
- 更新只替换程序文件，**不会修改你的布局、设置、背景媒体和网页登录状态**。
- 从源码运行时无法自动安装，按钮会变成 **前往下载**。

## 数据、隐私与安全

### 数据保存在哪里

默认在 `%LOCALAPPDATA%\DeskIsle`（**设置 → 关于 → 数据目录 → 打开**）：

| 位置 | 内容 |
| --- | --- |
| `state.json`、`state.json.bak` | 布局与设置（原子写入，并保留上一份备份） |
| `snapshots\` | 布局快照 |
| `media\`、`fonts\` | 导入的背景媒体、字体副本 |
| `web\WebView2\` | 网页岛的登录状态与缓存 |
| `custom\` | 自定义文件夹（默认位置） |
| `deskisle.log`、`crash.log` | 运行日志与崩溃信息 |

安装新版本和卸载都不会删除这个目录。想彻底清除数据时，先退出桌屿再删除它。

### 文件安全

- 普通收纳岛、归流规则、预设、快照只记录文件路径，**从不移动、重命名或删除原文件**。
- 删除普通收纳岛或预设时，其中的图标回到桌面散放区。
- 唯一会改动文件的操作是 **把文件拖进文件视窗**：执行前确认，可在资源管理器中 `Ctrl+Z` 撤销。
- 把图标拖到资源管理器等程序时，文件操作由那个程序执行（与从 Windows 桌面拖动相同）。
- 退出桌屿时恢复 Windows 原生桌面图标；意外退出时由守护进程恢复。

### 隐私

桌屿不包含任何遥测或使用统计。只有以下情况会联网：

- **天气**：只在桌面上有天气小组件时，请求 MSN 天气或 Open-Meteo；经纬度只保留两位小数。搜索城市时使用 Open-Meteo 地理编码。
- **检查更新**：请求 GitHub 的发布信息；只有点击“下载并安装”才会下载安装包。
- **网页岛**：访问你填写的网址，和普通浏览器一样。本地 HTML 与 HTML 小组件默认禁止联网。

正在播放只读取本机的系统媒体会话；Everything 搜索通过本机进程间通信完成；AI 接口只监听本机命名管道。

## 常见问题

**桌面原生图标不见了？**
这是 **由桌屿显示桌面图标** 的正常效果，图标都在桌屿的散放区或收纳岛里。退出桌屿时会自动恢复。
如果桌屿被强制结束且守护进程也被关闭，重新启动桌屿后正常退出即可；或在 Windows 桌面右键 → 查看 → 显示桌面图标。

**收纳岛全都不见了？**
可能处于清屏状态：双击桌面空白处、按 `Ctrl+Alt+H` 或点灵动岛的“恢复显示”。也可能切换到了另一个预设，点灵动岛的预设名称看看。

**删除收纳岛会删掉文件吗？**
不会。普通收纳岛只保存引用，删除后图标回到桌面散放区。删除文件视窗也不会删除真实文件夹。

**玻璃看起来是灰色 / 不透明，或者没有跟随动态壁纸？**
查看 **设置 → 外观 → 玻璃背景 → 动态壁纸状态**。部分系统无法读取动态壁纸，桌屿会自动改用静态壁纸；
也可以手动选择 **系统壁纸** 或 **自定义图片**。远程桌面或显卡驱动异常时，玻璃会退化为半透明底色。

**天气显示“暂时无法获取天气”或位置不对？**
检查 Windows“设置 → 隐私和安全性 → 定位”是否允许桌面应用访问位置；或关闭 **自动定位**，手动搜索城市。
桌面上没有天气小组件时，天气服务不会运行。

**正在播放没有显示？**
只有出现在 Windows 系统媒体控制（音量浮窗里的媒体卡片）中的播放器才能被读取；需要 Windows 10 1809 及以上。
网易云音乐需要在它的设置里打开 SMTC 相关选项，见 [正在播放](#正在播放)。

**网页岛空白或提示缺少 WebView2？**
安装 WebView2 运行时后点 **重试**。如果网页显示异常，把 **设置 → 桌面 → 网页显示方式** 改为 **窗口** 试试。

**网页点不动、不能输入？**
把 **设置 → 桌面 → 网页显示方式** 设为 **自动** 或 **窗口**（“合成（实验）”在部分电脑上无法交互）。

**桌屿占用内存很多？**
在 **设置 → 桌面 → 启动与性能 → 当前内存占用** 查看桌屿本体与网页组件各占多少。网页岛和 HTML 小组件每个都有自己的
WebView2 进程，是主要来源；确认 **空闲时释放内存** 已开启。

**快捷键没有反应？**
可能被其他程序占用（启动时会提示），或在设置中关闭了 **全局快捷键**。

**搜索不到电脑里的文件？**
安装并运行 Everything 可以搜索整台电脑；未安装时，内置索引只覆盖开始菜单、桌面和常用用户文件夹。

**AI 助手连不上？**
确认桌屿正在运行、**允许 AI 助手控制桌屿** 已打开，MCP 配置中的路径与 **设置 → AI 与扩展** 中显示的一致，修改配置后重启客户端。
`deskisle-cli desk.state` 返回退出码 3 表示桌屿未运行。

**怎样回到之前的布局？**
排布操作用 `Ctrl+Alt+Z`；更早的布局在 **设置 → 桌面 → 布局快照** 中恢复（升级、导入、恢复、更新之前都有自动快照）。

**怎样反馈问题？**
在 **设置 → 关于 → 运行日志** 打开 `deskisle.log`，连同 `crash.log`（如果有）一起附上。
