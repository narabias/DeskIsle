# 桌屿 2.0.1 需求与方案

> 来源：2.0.0 Windows 实机试用反馈（15 条）。
> 状态：13 项已全部实现并通过自动化测试（173 项）；标注“待 Windows 实机验收”的项依赖 WebView2、系统媒体会话等，只能在 Windows 上最终确认，见第四节清单。
> 原则：**快速修复、不做大改、优先手感**；能用现成方案（Windows / Qt / WebView2 自带能力）就不自己造；
> DeskBox、WinIsland 均为 GPL-3.0，且分别是 C# / Rust，代码不能直接搬进 MIT 的桌屿，**只借鉴思路**（见「待确认 1」）。

## 二、逐项说明

### R01 弹窗置顶且可拖动（删除确认、预设 / 搜索等面板、通知）
- **现象**：删除确认等卡片会被收纳岛、小组件（尤其网页组件）挡住；不能拖动。
- **根因**：这些卡片画在桌面层窗口里，和岛屿同一层；网页组件是原生窗口，会盖住同层的 Qt 内容；输入区域也只覆盖岛屿。
- **方案**：面板、确认卡、通知各自放进一个独立的置顶小窗口（Qt `Window` + `WindowStaysOnTopHint`），按需创建、隐藏后释放显存；
  卡片空白处按住即可拖动（系统自带 `startSystemMove`）；面板 / 确认卡在本次打开期间记住拖动后的位置，关闭后回到默认位置；
  通知不抢焦点（`WindowDoesNotAcceptFocus`）。设置窗口在前台时，确认卡仍在设置窗口内显示。
- **验收**：在网页组件、置顶岛上方打开预设面板、删除确认、通知，均完整显示且可点击；拖动卡片背景可移动；Esc 关闭面板 / 取消确认。

### R02 预设无法新建 / 保存
- **现象**：预设面板里“新建空白预设”“复制当前预设”、双击重命名无效。
- **根因**：同 R01——面板在桌面层窗口，点击被网页组件挡住；桌面层窗口不接收键盘，重命名输入框拿不到焦点。
- **方案**：随 R01 一起解决；弹窗窗口自己获得键盘焦点（输入框不再走桌面层借焦点的流程）。
- **验收**：新建、复制、重命名、删除预设均生效；重命名可直接打字、回车保存、Esc 取消。

### R03 收纳岛图标拖不出、不能换位
- **根因**：生成拖动预览图时传了空尺寸，图标服务报错，系统拖放从未真正开始；岛内换位走的是同一条拖放路径，所以一起失效。
- **方案**：已修复（图标服务对空尺寸做保护；拖动预览改用合法尺寸）。补单元测试。
- **验收**：图标可拖到桌面 / 资源管理器 / 其他岛；岛内拖动可换位（自动切到“手动排序”）。

### R04 小组件右键任意位置出菜单；网页组件好拖好删
- **现象**：小组件只有部分区域右键出岛屿菜单，其他地方出桌面菜单；网页组件几乎没有可拖动的地方。
- **根因**：小组件内容区没有兜底的鼠标区域，空白处的右键穿透到桌面；网页组件整块都是网页。
- **方案**：小组件内容区最底层加一个兜底鼠标区域：右键 → 岛屿菜单（含删除），左键按住拖动 → 移动岛屿；
  网页组件顶部保留约 24 px 的拖动条（悬停显示标题、刷新、菜单按钮），网页内右键也弹岛屿菜单（已有）。
- **验收**：任意小组件内任意位置右键都出岛屿菜单；网页组件可通过顶部拖动条拖动、右键删除。

### R05 网页组件无法交互
- **现象**：网页能显示，但点击、滚动、输入无反应；页面盖在其他内容上方。
- **根因**：合成托管模式下，WebView2 的视觉树没能放到 Qt 内容下方（Qt 已占用“非置顶”目标，只能退到置顶目标），
  页面画在所有 Qt 内容之上，而输入还靠 QML 转发，两者错位，所以点不动。
- **方案（现成方案）**：自动模式下只在“页面能放到 Qt 下方”时用合成托管；否则直接用 WebView2 官方的**窗口托管**
  （子窗口，原生鼠标 / 键盘 / 输入法，最稳）。设置 → 网页组件 → 托管方式保留“合成（实验）”供手动切换。
  键盘：页面获得焦点时通知桌面层接收键盘（WebView2 `GotFocus` 事件）。
- **取舍**：窗口托管下，其他岛拖过网页组件时会被页面盖住（弹窗已独立置顶，不受影响）。见「待确认 2」。
- **验收**：网页可点击、滚动、输入中文；右键出岛屿菜单；拖动 / 缩放组件时页面跟随；切预设、隐藏桌屿后页面暂停。

### R06 TODO：日期选择 + 日历显示 + 到点弹窗 + 消失动画
- **现象**：只能用“@明天 18:00”语法设日期；设了日期日历上看不到；到点没有明显提醒；完成 / 删除没有动画。
- **根因**：没有日期选择界面；时钟月历与待办数据不相通；提醒只是桌面层通知（被其他窗口挡住）且只提醒带时间的项；
  列表整体刷新，没有过渡。
- **方案**：
  1. 把时钟组件的月历抽成共用的**月历组件**，待办的日期选择和时钟月历用同一个组件、同一份数据 → 两边显示一致；
  2. 待办每项可点“日期”打开选择卡：月历 + 常用时间（不设时间 / 09:00 / 12:00 / 18:00 / 21:00 / 自定义），“清除日期”；
  3. 时钟月历上有待办的日期显示小圆点（过期红点），悬停显示当天待办；
  4. 到点提醒：置顶通知卡（R01）+ Windows 系统通知（托盘气泡 / Toast）；只设日期的项在当天 09:00 提醒；
     桌屿没开时错过的提醒，下次启动汇总提醒一次；
  5. 勾选完成 / 删除：先划线、淡出并收起高度（约 0.35 s），下面的项平滑上移；已完成项默认隐藏，底部显示“已完成 N 项”可展开 / 清除。
- **验收**：设置日期后，待办与时钟月历同一天都能看到；到点 30 秒内弹出置顶提醒和系统通知；完成 / 删除有平滑消失动画；重启后不重复提醒。

### R07 正在播放（识别、网易云、动效、封面取色）
- **现象**：切歌 / 暂停反应慢；网易云识别不到；封面偶尔是绿色占位；动效生硬；高布局封面压住标题；玻璃颜色不随封面。
- **根因**：媒体服务每 1 s（空闲 4 s）轮询系统媒体会话（GSMTC），没有订阅事件；会话选择顺序不合理（暂停的浏览器可能压过正在播放的应用）；
  封面缩略图到得比标题晚时直接显示占位；网易云音乐默认不向系统报告播放信息。
- **方案（现成方案）**：
  1. 订阅 GSMTC 自带事件（会话增减、当前会话变化、媒体信息变化、播放状态变化、进度变化），轮询降为兜底；进度条本地插值；
  2. 会话优先级：用户手选 > 正在播放的当前会话 > 任一正在播放 > 当前会话 > 第一个；
  3. 封面晚到时保留上一张并自动重试（0.3 s / 1 s / 3 s），没有封面时显示中性玻璃 + 音符；
  4. 网易云：检测到网易云在运行但没有媒体会话时，空状态提示“在网易云音乐设置中打开 SMTC”；歌词 / 进度需 BetterNCM（引用 WinIsland 常见问题的结论）；
  5. 封面取色：Qt 自带缩放取封面主色作为强调色（进度条、按钮），封面极小尺寸放大 + Qt `MultiEffect` 模糊作为玻璃内的氛围底色
     （思路同 WinIsland / Apple Music 的“封面光晕”，零第三方依赖），颜色变化 0.6 s 渐变；
  6. 动效：封面 / 标题交叉淡入，进度条线性平滑，播放 / 暂停图标轻量切换，去掉弹跳；布局按尺寸自适应（宽：左封面右文字；高：上封面下文字）。
- **验收**：切歌、暂停 0.5 s 内更新；网易云开启 SMTC 后可识别，未开启时有提示；封面不再闪绿；玻璃底色随封面变化且文字清晰；任意尺寸不重叠。

### R08 布局快照可删除
- **方案**：设置 → 桌面 → 布局快照每项加“删除”（二次确认），只允许删除快照文件夹内的文件；可选“仅保留最近 N 个自动快照”（见「待确认 4」）。
- **验收**：删除后列表即时刷新，文件已移除；恢复、导出不受影响。

### R09 全局字体颜色
- **方案**：设置 → 外观新增“文字颜色”：自动（跟随主题 / 壁纸明暗）/ 浅色 / 深色 / 自定义（取色）；
  主文字、次要文字、弱化文字按同一颜色按比例变淡，强调色不变；作用于岛屿、小组件、灵动岛、菜单和弹窗。
- **验收**：切换后所有桌面元素文字立即变色；自定义颜色重启后保留；“自动”与 2.0.0 表现一致。

### R10 设置界面闪烁
- **根因**：设置窗口背景每次壁纸变化（动态壁纸会频繁变化）都重新加载模糊壁纸并硬切换；部分主题信号在值未变时也触发重绘。
- **方案**：背景只在打开设置、壁纸真正换图时刷新，并且新旧背景交叉淡入；主题只在数值真正变化时通知。
- **验收**：动态壁纸下打开设置 1 分钟无闪烁；更换壁纸后背景平滑过渡。

### R11 翻页时钟
- **方案**：翻页样式隐藏“显示秒”选项（设置页与组件菜单），冒号不再随秒闪烁；去掉数字中间的暗色分割线，改为卡片上下半区轻微明暗差。
- **验收**：翻页样式下看不到“显示秒”；数字中间无横线；数字 / 指针样式的“显示秒”照常可用。

### R12 拖动手感
- **方案**：拖动时只移动岛屿本身，让位计算节流到每帧一次并在松手时一次性落位；拖动期间关闭阴影 / 模糊的实时重算；
  松手吸附用短促缓动（约 160 ms），取消弹性回弹；按下后移动超过 4 px 才开始拖动，避免误拖。
- **验收**：60 Hz 显示器上拖动岛屿、小组件跟手无顿挫；松手吸附自然。

### R13 内存占用
- **说明**：任务管理器“桌屿”分组包含 WebView2 子进程（msedgewebview2.exe，每个网页组件约 100–200 MB）；
  DeskBox 是 .NET Native AOT + WinUI，基线约 128 MB，桌屿是 Python + Qt Quick，基线会高一些。
- **方案（全部是官方现成接口）**：
  1. WebView2：组件隐藏 / 桌屿隐藏 / 切走预设时 `TrySuspend` + `MemoryUsageTargetLevel = Low`，恢复时还原；
  2. Qt：隐藏的窗口（设置、菜单、弹窗）调用 `QQuickWindow::releaseResources()`；设置窗口关闭一段时间后销毁；
     图片一律设 `sourceSize`，模糊壁纸纹理按屏幕 1/4 尺寸生成；
  3. Windows：启动稳定后、关闭设置后各做一次工作集修剪（`SetProcessWorkingSetSize(-1, -1)`），带下限与冷却，不做周期性强制回收
     （DeskBox 也是“空闲修剪 + 限制缓存”，后来去掉了强制修剪，这里只在明确空闲点做一次）；
  4. 设置 → 性能里显示当前内存（桌屿本体 / 网页组件），方便对比。
- **目标**：见「待确认 3」，建议：无网页组件空闲 ≤ 250 MB；每个网页组件另计。
- **验收**：同一布局下对比 2.0.0，空闲内存明显下降；隐藏网页组件后其子进程内存下降。

## 三、待确认事项（未回复则按“默认”执行；结论见每条箭头后）

6. **TODO 提醒**：默认到点提醒、只设日期的项当天 09:00 提醒、不提前、使用系统通知声音；是否需要“提前 5 / 15 / 30 分钟”？

7. **翻页时钟**：默认翻页样式完全不显示秒。→ **按默认执行**。
8. **封面变色范围**：默认只作用于正在播放组件和灵动岛的媒体胶囊，不改全局强调色。→ **按默认执行**。

## 四、Windows 实机验收清单

1. 安装 2.0.1 覆盖 2.0.0，确认原布局、快照保留。
2. R03：从收纳岛拖图标到桌面、到资源管理器、到另一个岛；岛内互换位置。
3. R01 / R02：在网页组件上方打开预设面板，新建、复制、重命名、删除预设；删除确认卡可拖动、Esc 可取消。
4. R04 / R05：网页组件（如 bing.com）点击、滚动、输入中文；顶部拖动条拖动；任意位置右键删除；其他小组件空白处右键。
5. R06：新建待办“测试 @今天 HH:MM”（填 2 分钟后的时间；或点日期按钮在日期卡里选）→ 时钟月历出现圆点、点击可看当天待办 → 到点弹出置顶提醒和系统通知，试“10 分钟后”与“完成” → 勾选完成 / 删除看到消失动画。
6. R07：分别用网易云（开 / 关 SMTC）、QQ 音乐、Edge 播放 B 站视频，看识别速度、封面、颜色、动效。
7. R08 ~ R11：删除快照；切换文字颜色四种模式；动态壁纸下开设置 1 分钟；翻页时钟检查。
8. R12：拖动岛屿、小组件各 10 次，感受跟手与吸附。
9. R13：开机 5 分钟后记录任务管理器内存（展开分组，分别记录 DeskIsle.exe 与 msedgewebview2.exe）。
